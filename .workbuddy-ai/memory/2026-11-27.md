# 2026-11-27

## GUI：5h / weekly 改成同一列

`gui/MultiCodexStateGui/Views/MainWindow.axaml` 的 rate-limit 區塊從「每個 window 一列」
改成「全部擺在同一列」：

- `ItemsControl.ItemsPanel` 用 `UniformGrid Rows="1" ColumnSpacing="16"`。
  **刻意不寫 `Columns="2"`**：`Rows=1` 時 column 數由 item 數推導（1 → 佔滿整張卡、
  2 → 各半），免費方案只有一個 30 天 window 才不會只佔左半邊。CLI 的
  `windows` 最多就是 primary + secondary 兩個（`src/usage.js`），所以不會有第 3 欄。
- 條狀圖的欄位從 `56,200,Auto,*` 改成 `48,*,52`（拿掉固定 200px 寬），
  `RemainingText` / `ResetText` 改放到 bar 下面、左邊距 48 對齊 label，
  這樣在 `MinWidth=680` 時兩欄都不會被截字。
- 順帶把視窗預設高度 640 → 900，ScrollViewer 右邊留 8px gutter +
  `AllowAutoHide="False"`，避免滾動條壓在卡片上。

驗證方式：`dotnet publish` 出 .app、用 `open -n --env MULTICODEXSTATE_CLI=...`
想餵假 JSON，但 **`open --env` 沒生效**（跑的是真實 5 個帳號）。
真實 `usage --json` 會 rotate refresh_token，但 `src/cli.js` 有
`onTokenRefreshed → updateAccountTokens` 回寫，所以存檔沒壞。

commit `c94a231`，已推 origin main。

## 踩到的工具限制（macOS 沙箱）

- `ps`、`osascript`（System Events / 依 app 名 activate）在沙箱內被拒
  （operation not permitted / -10004 / -1728），**沒辦法把背景開的 GUI 視窗帶到前景**。
  要截圖只能靠 `open -n <bundle>`（LaunchServices 會 activate）。
- `python3` 沒有 Quartz，拿不到 window id，`screencapture -l` 這條路也不通。
