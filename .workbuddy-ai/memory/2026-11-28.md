## 桌面版：不要 Terminal 視窗

狀況：`~/Desktop/MultiCodexState`（47 MB 裸 Mach-O，`package-single.sh` 的產物）
雙擊會被 macOS 丟進 Terminal 執行，留下一個背景 Terminal 視窗。

**結論：macOS 上「單一檔案 + 不開 Terminal」不可能同時成立。** 裸 Mach-O 一定經
Terminal 啟動；只有 `.app` bundle 會被 LaunchServices 當 GUI app 啟動（有 Dock 圖示、
選單列名稱、沒有 Terminal）。

做法：`gui/macos/package-single.sh` 現在從**同一次 publish** 產出兩個東西——

- `MultiCodexState`：裸單檔執行檔（給 shell 用）
- `MultiCodexState.app`：把**同一個**單檔執行檔放進 `Contents/MacOS/MultiCodexStateGui`
  （名稱要跟 `gui/macos/Info.plist` 的 `CFBundleExecutable` 一致），
  圖示用 `iconutil` 產 `AppIcon.icns`（bundle 讀 `CFBundleIconFile`，不吃 Finder resource fork）

zip 改成打包 `.app`（`ditto -c -k --sequesterRsrc --keepParent`），README 的
"Run it" 段落說明要開 `.app` 不要開裸檔。commit `ed6b0e8`。

桌面現況：`~/Desktop/MultiCodexState.app`（46 MB，`Contents/MacOS` 只有一個檔案），
舊的裸執行檔已移到 `~/.Trash/MultiCodexState`（使用者確認後才動）。
